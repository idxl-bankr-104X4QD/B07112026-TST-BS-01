Добавить или обновить акт

← к базе

1. Файл с zakon.rada.gov.ua

На сайте Рады откройте акт → «Завантажити» → HTML. Можно несколько файлов сразу. Если акт уже есть в базе, он заменится новой редакцией (по номеру). Старые акты в «жёстком» формате (строки по 60 знаков) склеиваются в абзацы автоматически.

Перетащите .htm/.html файлы сюда или нажмите, чтобы выбрать

2. Опубликовать

Автоматически: страница сама запишет файлы в ваш репозиторий GitHub (нужен токен, инструкция ниже). Вручную: скачайте файлы и загрузите их в папку data репозитория через Add file → Upload files.

3. Акты в базе

Здесь можно изменить название и реквизиты акта или удалить его с сайта (нужен токен из шага 2). Удаление: нажмите «Удалить» два раза подряд. Список берётся из GitHub, поэтому показывает актуальное состояние.

Как создать токен (один раз)

GitHub → ваш аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: Only select repositories → ваш репозиторий. Permissions → Repository permissions → Contents: Read and write. Срок действия выберите длинный, скопируйте токен и вставьте выше. Токен даёт доступ только к этому репозиторию.
